```markdown
## 段0 开场钩子
- 你按下 A 键，马里奥跳了起来。
- 这一帧画面，停留在屏幕上只有十六毫秒。
- 但就在这十六毫秒里，机器内部发生了几百万件事。
- 今天我们把这一帧拆开，看它到底是怎么诞生的。

## 段1 什么是模拟
- 先问一个最朴素的问题：模拟器到底在模拟什么？
- 一台真的 GBA，是一堆芯片在协同工作。
- 而模拟器，是用软件复刻每一块芯片的行为。
- 在 mGBA 的源码里，整台机器就是一个结构体。
- 我们看一眼它的开头几行。
- CPU、内存、视频、音频、时钟，五大件都在这里。
- 这一集不深讲代码，只让你先认认脸。

## 段2 主角登场
- 这台机器有五个主角，外加一位隐形的指挥。
- 第一位，CPU，一颗 ARM7 处理器，负责执行游戏的指令。
- 第二位，内存，存放代码、数据和画面。
- 第三位，PPU，把数据画成屏幕上的像素。
- 第四位，APU，负责声音。
- 第五位，DMA，一个不打扰 CPU 的高速搬运工。
- 还有一根贯穿全场的时钟，让所有人对得上拍子。

## 段3 一帧的旅程·上
- 旅程从你的手指开始。
- 按键被记录到一块内存里。
- CPU 取出下一条指令，解码，然后执行。
- 它根据游戏逻辑，算出马里奥这一帧该在哪里。
- 然后把结果写进显存。

## 段4 一帧的旅程·下
- 接力棒交给 DMA，它把数据高速搬进画面缓冲。
- PPU 登场，一行一行地扫描。
- 从屏幕最上面一行，画到最下面一行。
- 当最后一行画完，一整帧就亮在了屏幕上。
- 与此同时，APU 把这一帧该响的声音也合成好了。

## 段5 隐形的主宰
- 但这里有个问题：这么多部件，凭什么对得齐？
- 答案是那根隐形的时钟。
- 每个部件做的每件事，都要花掉确定数量的时钟周期。
- mGBA 用一个事件调度器统一管理时间。
- 谁该在第几个周期做事，它都安排得明明白白。
- 这就是模拟器最核心的难题，周期精确。

## 段6 系列地图
- 现在，把刚才这趟旅程画成一张地图。
- 后面每一集，我们都会停在地图的某一站，往里深挖。
- 下一集，我们从 CPU 开始：软件怎么假装成一块芯片。
- 这趟旅程，才刚刚开始。
```

```python
    def code_card(self, lines, title="", w=8.0, fs=22, hl=None):
        """代码特写卡片：深色圆角面板 + 等宽代码 + 可选标题/高亮行。
        lines: 代码字符串列表；hl: 需高亮的行号集合(0-based)。返回 VGroup。"""
        hl = hl or set()
        code_lines = VGroup()
        for i, ln in enumerate(lines):
            c = GOLD if i in hl else "#d7e3fc"
            t = Text(ln if ln else " ", font="Menlo", font_size=fs, color=c)
            code_lines.add(t)
        code_lines.arrange(DOWN, aligned_edge=LEFT, buff=0.16)
        panel = RoundedRectangle(width=w, height=code_lines.height + 0.9,
                                 corner_radius=0.18, color=GREY,
                                 stroke_width=2, fill_color="#10243a", fill_opacity=0.95)
        code_lines.move_to(panel.get_center())
        grp = VGroup(panel, code_lines)
        if title:
            cap = Text(title, font="Menlo", font_size=fs - 4, color=GREY)
            cap.next_to(panel, UP, buff=0.15).align_to(panel, LEFT)
            grp.add(cap)
        return grp
```

- [ ] **Step 3: 新增 flow_pipeline() 工具方法**

```python
    def flow_pipeline(self, labels, colors, y=0.0, w=2.2, h=0.9, gap=0.5):
        """水平数据流：一排节点 + 节点间箭头。返回 (nodes:VGroup, arrows:VGroup)。
        逐站高亮时对 nodes[i] 做 indicate / 改 stroke。"""
        nodes = VGroup()
        for lbl, col in zip(labels, colors):
            nodes.add(self.node(lbl, col, w=w, h=h, fs=18))
        nodes.arrange(RIGHT, buff=gap).move_to(UP * y)
        arrows = VGroup()
        for i in range(len(nodes) - 1):
            arrows.add(Arrow(nodes[i].get_right(), nodes[i + 1].get_left(),
                             color=GREY, buff=0.08, stroke_width=3, max_tip_length_to_length_ratio=0.2))
        return nodes, arrows
```

```python
        self.P(nodes.animate.scale(0.8).to_edge(UP, buff=1.2), run_time=0.4)

    def seg4_journey_b(self):
        head = self.head("四、一帧的旅程 · 下")
        self.P(FadeIn(head), run_time=0.3)
        dma = self.node("DMA", "#a06cd5", w=2.2, h=0.9, fs=18).move_to(UP * 0.2 + LEFT * 4)
        ppu = self.node("PPU", GOLD, w=2.2, h=0.9, fs=18).next_to(dma, RIGHT, buff=0.8)
        a1 = Arrow(dma.get_right(), ppu.get_left(), color=GREY, buff=0.08, stroke_width=3)
        screen = RoundedRectangle(width=4.2, height=2.8, corner_radius=0.15, color=WHITE,
                                  stroke_width=2.5, fill_color="#0a1828", fill_opacity=1).to_edge(RIGHT, buff=1.2)
        scanline = Line(screen.get_corner(UL), screen.get_corner(UR), color=ACCENT, stroke_width=3)
        speaker = Text("♪", font_size=40, color=WARN).next_to(screen, DOWN, buff=0.2)
        self.beat(intro_anims=[FadeIn(dma)], intro_t=0.7)                               # DMA 搬运
        self.beat(intro_anims=[GrowArrow(a1), FadeIn(ppu)], intro_t=0.7)                # PPU 登场
        self.beat(intro_anims=[FadeIn(screen), Create(scanline)], intro_t=0.8)          # 一行行扫描
        self.beat(intro_anims=[scanline.animate.move_to(screen.get_bottom() + UP * 0.1)], intro_t=1.0)  # 扫到底
        self.beat(intro_anims=[Flash(screen, color=GOLD, flash_radius=2.6),
                               FadeIn(speaker, scale=1.3)], intro_t=0.9)                 # 整帧亮起+APU出声
        self.P(FadeOut(VGroup(head, dma, ppu, a1, screen, scanline, speaker,
                              self.journey_nodes)), run_time=0.4)

    def seg5_clock(self):
        head = self.head("五、隐形的主宰")
        self.P(FadeIn(head), run_time=0.3)
        mods = VGroup(*[self.node(n, c, w=2.0, h=0.7, fs=16) for n, c in
                        [("CPU", ACCENT), ("PPU", GOLD), ("DMA", "#a06cd5"), ("APU", WARN)]])
        mods.arrange(RIGHT, buff=0.5).to_edge(UP, buff=1.3)
        axis = Line(LEFT * 5.5, RIGHT * 5.5, color=GREY, stroke_width=3).move_to(DOWN * 1.0)
        ticks = VGroup(*[Line(UP * 0.12, DOWN * 0.12, color=GREY).move_to(
            axis.get_left() + RIGHT * (i * 11 / 6 + 0.5)) for i in range(7)])
        tlabel = Text("时钟周期 →", font=CN, font_size=18, color=GREY).next_to(axis, DOWN, buff=0.25).to_edge(RIGHT, buff=1.5)
        card = self.code_card(
            ["void mTimingSchedule(",
             "  struct mTiming*,",
             "  struct mTimingEvent*,",
             "  int32_t when);"],
            title="src/core/timing.c", w=5.2, fs=18).move_to(DOWN * 2.3)
        self.beat(intro_anims=[FadeIn(mods)], intro_t=0.7)                              # 凭什么对得齐
        self.beat(intro_anims=[Create(axis), Create(ticks)], intro_t=0.8)              # 那根隐形时钟
        self.beat(intro_anims=[FadeIn(tlabel)], intro_t=0.6)                           # 每件事花确定周期
        self.beat(intro_anims=[FadeIn(card)], intro_t=0.9)                             # 事件调度器
        self.beat(intro_anims=[Indicate(card, color=ACCENT)], intro_t=0.7)            # 安排得明明白白
        self.beat(intro_anims=[Indicate(tlabel, color=GOLD)], intro_t=0.7)            # 周期精确
        self.P(FadeOut(VGroup(head, mods, axis, ticks, tlabel, card)), run_time=0.4)

    def seg6_map(self):
        head = self.head("六、系列地图")
        self.P(FadeIn(head), run_time=0.3)
        episodes = ["序章", "CPU", "指令", "内存", "时钟",
                    "DMA", "PPU", "BIOS", "声音", "存档"]
        dots = VGroup()
        for i, name in enumerate(episodes):
            d = Dot(radius=0.12, color=GREY)
            lb = Text(name, font=CN, font_size=14, color=GREY).next_to(d, DOWN, buff=0.12)
            dots.add(VGroup(d, lb))
        dots.arrange(RIGHT, buff=0.55).move_to(ORIGIN)
        path = Line(dots[0].get_center(), dots[-1].get_center(), color=GREY, stroke_width=2).set_z_index(-1)
        self.beat(intro_anims=[Create(path), FadeIn(dots)], intro_t=1.0)               # 画成一张地图
        self.beat(intro_anims=[dots[0][0].animate.set_color(ACCENT),
                               dots[0][1].animate.set_color(ACCENT)], intro_t=0.8)      # 每集停一站
        self.beat(intro_anims=[Indicate(dots[1], color=GOLD, scale_factor=1.4)], intro_t=0.9)  # 下一集 CPU
        end = Text("这趟旅程，才刚刚开始", font=CN, font_size=30, color=ACCENT, weight=BOLD).move_to(DOWN * 2.2)
        self.beat(intro_anims=[Write(end)], intro_t=1.0)                               # 才刚刚开始
        self.P(FadeOut(VGroup(head, dots, path, end)), run_time=0.6)
```

> 说明：`Flash`、`Indicate`、`GrowArrow`、`Create`、`Dot` 均为 manim 内置；`set_z_index(-1)` 让地图连线在节点下方。每段实现后用 Step 5 校验 beat() 总数 == 句数 N。
